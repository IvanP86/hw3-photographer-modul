# ADR-0001: Обработка списка товаров для перефотографирования

- Статус: Proposed

## Контекст

Фотограф получает из 1С файл `arts.txt` со списком товаров, сгруппированных по складам. Для товаров нужно просматривать изображение, артикул и наименование, чтобы решить, требуется ли перефотографирование.

Если изображение устраивает, товар нужно убрать из текущего списка. Удалять товар из базы нельзя. При необходимости фотограф может повторно выгрузить список из 1С, поэтому сохранять удаленные из списка позиции отдельно не требуется. В списке могут быть тысячи товаров, поэтому интерфейс не должен требовать отмечать каждый товар чекбоксом.

## Решение

Страница обрабатывает товары последовательно, по одному: показывает изображение, артикул и наименование, а фотограф решает, оставить товар для перефотографирования или убрать его из текущего списка. Удаление выполняется отдельным действием для текущего товара; после него показывается следующий. Перед удалением запрашивается подтверждение.

Убранный товар исключается из текущего файла `arts.txt` и не удаляется из базы данных. Отдельно хранить его или историю удаления не требуется: исходный список можно заново выгрузить из 1С.

По оставшимся товарам страница формирует результирующие TXT-файлы по складам для сборки на перефотографирование.

## Последствия

- Фотографу не нужно вручную отмечать чекбоксами тысячи позиций.
- Текущий `arts.txt` отражает товары, которые еще нужно рассмотреть или перефотографировать.
- Товары с подходящими изображениями не попадут в результирующие файлы.
- Удаление из текущего файла является необратимым в рамках этой обработки; для восстановления нужно заново выгрузить файл из 1С.
- Подтверждение перед удалением снижает риск случайно исключить товар.
- Товарная база остается неизменной.

## Альтернативы

- **Не изменять исходный файл, а хранить отдельный список решений.** Отклонено: фотограф может заново получить файл из 1С, поэтому хранить исключенные позиции отдельно не требуется.
- **Отмечать товары чекбоксами и удалять пакетно.** Отклонено: обработка тысяч чекбоксов создает лишние действия и повышает риск ошибки; товары будут просматриваться по одному.
- **Удалять товар из базы.** Отклонено: решение относится только к подборке на перефотографирование и не должно менять данные 1С/товарной базы.

## Условие пересмотра

Пересмотреть решение, если потребуется сохранять прогресс между разными файлами 1С, восстанавливать ранее исключенные товары без повторной выгрузки или вести историю решений фотографа.
