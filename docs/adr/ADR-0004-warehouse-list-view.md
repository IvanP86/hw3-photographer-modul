# ADR-0004: Просмотр всех товаров выбранного склада

- Статус: Proposed
- Дополняет: [ADR-0001 — Обработка списка товаров для перефотографирования](./ADR-0001-photograf-selection-flow.md)
- Реализуется в рамках: [ADR-0003 — Реализация страницы фотографа на SOLID без DDD](./ADR-0003-solid-photographer-module.md)

## Контекст

Первоначальный сценарий предполагал просмотр одного товара и переход к следующему. Для длинного складского списка такие переходы добавляют лишние действия и замедляют оценку фотографий.

## Решение

Показывать все товары выбранного склада на одной странице в виде карточек с фотографией, артикулом, наименованием и отдельным действием удаления. Фотограф выбирает склад, затем просматривает его список целиком; навигация по одному товару не является основным режимом.

Товар без фотографии остаётся среди товаров своего склада и показывается с заглушкой, без отдельной классификации только по отсутствию изображения. Удаление выполняется для выбранной карточки с подтверждением и меняет только текущий `arts.txt`. Складские и ненайденные TXT по-прежнему формируются только по явной команде.

Для выбранного склада данные каталога следует получать пакетно, а не выполнять отдельный запрос Bitrix на каждую карточку.

## Последствия

- Фотограф видит весь список склада без переходов между товарами.
- Можно быстро сравнивать фотографии соседних товаров.
- Страница и передача изображений могут быть длинными для складов с большим числом товаров; изображения следует загружать лениво.
- Пакетное получение карточек уменьшает число запросов к Bitrix по сравнению с запросом на каждую карточку.
- Сохранение остальных складских, файловых и безопасностных правил ADR-0001—ADR-0003 не меняется.

## Альтернативы

- **Оставить только просмотр по одному товару.** Отклонено: добавляет лишние переходы при просмотре склада.
- **Показывать все склады на одной странице.** Отклонено: усложняет поиск нужного товара и загружает лишние изображения; фотограф выбирает склад и видит его список целиком.
- **Выводить все товары склада, но загружать карточку отдельным запросом на каждый товар.** Отклонено: создает лишнюю нагрузку на Bitrix; применяется пакетный запрос для выбранного склада.

## Условие пересмотра

Пересмотреть решение, если в одном складе регулярно будет слишком много товаров для одной страницы или пакетная загрузка будет превышать допустимое время ответа; тогда рассмотреть пагинацию либо виртуализацию списка без возврата к переходам по одному товару.
