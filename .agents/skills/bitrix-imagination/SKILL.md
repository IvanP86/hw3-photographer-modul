## Когда применять
- Когда задача затрагивает отображение товаров, получение товарных данных или изображений из Bitrix либо удаление товара из списка.

## Правило (уже принятое, не обсуждается)
1. Если в проекте подключено ядро битрикса, то превью генерируем через `CFile::ResizeImageGet`, с размером 300 на 300 кеш не чистим, если нет используем заглушку 300 на 300.
2. Если подключено ядро битрикса, достаем Детальную картинку и наименование товара из базы данных, где артикул из файла артикулов соотвествует свойству `CML2_ARTICLE` с id 59 инфоблока каталога, если ядро не подключено, используем псевдо данные.
3. Если подключено ядро Битрикса, только авторизированные пользователи с id = 1 или id = 357 могут запускать модуль//скрипт или любой другой код. Если это локальная разработка, то любой пользователь, даже не авторизированный.
4. Если пользователь нажимает «удалить», то всегда уточняй подтверждение
5. После удаления артикула выведи надпись Хе-хе-хе
